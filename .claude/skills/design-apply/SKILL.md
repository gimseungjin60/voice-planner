# design-apply

시안을 **보기만 바꾸고 동작은 그대로** 옮기는 작업이다. 화면별 대응표와 건드리면 안 되는 선택자는 `docs/design/ui-map.md`에 있다. 작업 전에 반드시 읽는다.

## 지켜야 할 것 (과제 제약)
- 스택 유지: EJS + `public/css/style.css` 하나 + 바닐라 JS. Tailwind·React·빌드 도구·CSS 프레임워크 추가 금지
- 시안이 Tailwind/React 코드로 와도 **구조와 수치만 읽고** 순수 CSS 클래스로 다시 쓴다 (유틸리티 클래스 복붙 금지)
- 외부 리소스는 웹폰트(`<link>` 한 줄, 예: Pretendard CDN)와 이모지/인라인 SVG 아이콘까지만. 아이콘 라이브러리 패키지 설치 금지
- 라우터·API·DB·`public/js/*.js`의 로직은 바꾸지 않는다. 마크업 변경 때문에 JS 선택자가 깨지면 **마크업 쪽을 맞춘다**
- 시안에 있지만 명세(`@Dev.md`)에 없는 기능(검색창, 알림, 다크모드 토글 등)은 만들지 말고 목록으로 사용자에게 제안
- UI 문구는 한국어 유지. 시안의 영어 placeholder는 현재 문구로 바꾼다

## 순서
1. **입력 정리**: 받은 것(이미지/HTML/DESIGN.md/Figma 링크)을 읽고 아래를 표로 뽑는다
   - 색(배경·카드·글자·보조·선·주색·위험·경고·성공), 폰트, 글자 크기 단계, radius, 그림자, 간격 단위, 브레이크포인트
   - 화면별 레이아웃 변화 (어느 화면이 시안에 있고 어느 화면이 없는지)
2. **1단계 토큰 교체**: `style.css`의 `:root` 변수만 시안 값으로 바꾼다. 새 토큰이 필요하면 `:root`에 추가하고 하드코딩 색(`#eceef5`, `#fff`, `rgba(108,142,245,…)` 등)도 변수로 끌어올린다. 이 단계만으로 전 화면이 바뀌는지 먼저 확인
3. **2단계 컴포넌트**: `ui-map.md`의 공통 컴포넌트(nav, card, btn, input, chip, list, mic, tabs, toast, pager)를 시안 모양으로 다시 쓴다. 클래스 이름은 유지하고 속성만 바꾼다
4. **3단계 화면 레이아웃**: 시안에 있는 화면만 `views/*.ejs` 구조를 바꾼다. 이때 `ui-map.md`의 "고정 id·클래스"는 이름과 역할을 그대로 남긴다. JS가 만들어 넣는 마크업(`tasks.js`의 `card()`, `dashboard.js`의 top-list, `memo.js` 후보 템플릿)도 같은 디자인으로 맞춘다
5. **시안에 없는 화면**: 같은 토큰·컴포넌트로 톤만 맞춘다 (구조 변경 최소)
6. **반응형**: 시안에 모바일이 없으면 760px 이하에서 1열로 무너지게 직접 설계 (nav 줄바꿈, board 1열, 표 가로 스크롤)
7. **검증**
   - `npm run check` 통과
   - Playwright로 9개 화면을 데스크톱(1280)·모바일(390) 스크린샷 → 시안과 나란히 비교, 차이 목록 작성
   - 동작 확인: 로그인, 마이크 버튼 녹음 상태(`.recording`), AI 분석 결과 표시, 할 일 이동/삭제, 과목 추가 폼 열기, 로그아웃
   - 제출용이면 `docs/screenshots/`에 저장
8. **커밋**: 단계별로 나눈다 — `style: 디자인 토큰 교체` → `style: 공통 컴포넌트 시안 반영` → `style: 대시보드 화면 시안 반영` …

## 보고 형식
- 적용한 화면 / 시안과 다르게 둔 곳과 이유 / 명세 밖이라 제안만 한 요소 / 스크린샷 경로

## 사용자에게 보낼 재사용 프롬프트
사용자가 시안만 던지고 말이 없을 때도 아래를 요청받은 것으로 간주하고 진행한다.

> 첨부한 디자인(시안/DESIGN.md)을 보이스 플래너에 적용해줘. design-apply 스킬과 docs/design/ui-map.md 기준으로,
> 토큰 → 공통 컴포넌트 → 화면 순서로 하고 기능·API·JS 로직은 건드리지 마. 시안에 있는데 명세에 없는 요소는 만들지 말고 따로 알려줘.
> 끝나면 데스크톱·모바일 스크린샷이랑 시안 비교 결과를 보여줘.
