| 용도 | 방식 | 비용 |

## 4. DB 연결 전 전체 구성 점검

| 점검 | 결과 |
|---|---|
| `npm run check` 문법 검사 | 29개 통과 |
| 전체 화면 13개 렌더 (미리보기) | 모두 200 |
| 전체 화면 브라우저 콘솔 오류 | **1건 발견 → 수정** 후 0건 (아래) |
| 코드가 쓰는 컬럼 ↔ `schema.sql` | 7개 테이블 모두 일치 |
| 본인 데이터만 (`user_id`) | 모든 조회·수정 확인. 수정 후 재조회는 `UPDATE … AND user_id = ?`로 먼저 막음 |
| SQL `?` 플레이스홀더 | 문자열 연결 쿼리 없음 (동적 부분은 컬럼명·WHERE 조각뿐) |
| 화면이 부르는 API ↔ 서버 라우트 | 아래 6장의 미구현 API 외 모두 존재 |
| 미구현 API 호출 시 화면 | 깨지지 않음 (받은 편지함 '구글 연결해 주세요', 연동 '연결 안 됨') |

점검 중 고친 것:
- **할 일 보드 오류**: 모바일 열 전환을 지우면서 남은 `[data-count]` 참조 때문에 첫 열만 그리고 멈추던 문제 → 해당 줄 삭제 (`public/js/tasks.js`)
- **세션 쿠키**: `secure: "auto"` 추가 → EC2 HTTPS에서는 secure 쿠키, 로컬 http는 그대로

## 7. EC2 배포 시 반영 사항 (`.claude/skills/ec2-deploy/SKILL.md`에 추가함)

- nginx `client_max_body_size 25m` (기본 1MB면 강의 녹음 조각이 413), `proxy_read_timeout 120s`, `X-Forwarded-Proto` 헤더
- 보안그룹 80·443 열기, 3306은 닫기. 아웃바운드로 api.anthropic.com·api.openai.com 호출
- 마이크(Web Speech, MediaRecorder)는 HTTPS 필수 → 도메인 + certbot
- pm2는 fork 모드 1개 (브리핑 음성 캐시가 프로세스 메모리)
- `.env`에 `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `SESSION_SECRET`, `DB_*` 필요. EC2에서 사용자가 직접 입력
- OpenAI 대시보드에서 월 사용 한도 $4 설정 권장
