# 기능별 디자인 프롬프트 (Claude Design용)

> 사용법: 맨 위 **공통 프롬프트**를 한 번 보낸 뒤, 화면마다 아래 프롬프트를 하나씩 붙여 넣는다.
> 프롬프트는 "무슨 기능인지"만 설명한다. 색·글꼴·모양은 초안 디자인을 그대로 쓴다.
> 기준: 실제 구현된 화면(`views/*.ejs`)과 데이터. 예시 데이터는 미리보기 서버(`npm run preview`)와 같다.

---

## 0. 공통 프롬프트 (처음 한 번)

```
지금까지 만든 보이스 플래너 초안 디자인(색, 글꼴, 간격, 버튼·카드·입력창 모양)을 디자인 시스템으로 삼아줘.
앞으로 화면을 하나씩 요청할 텐데, 새 스타일을 만들지 말고 이 초안의 컴포넌트를 그대로 재사용해서 기능만 입혀줘.

서비스: "보이스 플래너" — 대학생이 말하면 AI가 할 일·마감·과목을 정리해 주고, 시간표·구글 캘린더·학교 메일을 한 화면에 모아주는 웹 플래너.
조건:
- PC 웹 전용, 기준 폭 1280px (모바일 화면은 만들지 않음)
- 모든 문구는 한국어, 친근한 존댓말("~해요")
- 모든 화면 공통: 상단 내비게이션(대시보드·음성 메모·메모·할 일·시간표·리포트·받은 편지함·연동·관리자, 오른쪽에 사용자 이름·로그아웃), 오른쪽 아래 떠 있는 "비서에게 말하기" 버튼
- 과목마다 고유 색이 있음(예: 심화응용프로젝트 #6C8EF5, 데이터베이스 #F5A86C, 운영체제 #7CC9A0). 과목 칩·시간표 블록에 이 색을 옅게 깔아 써줘
- 마감 표시 규칙: 24시간 이내 빨강, 3일 이내 주황, 그 외 회색. 표기는 "D-day · 11/23 21:00", "D-3 · 11/26 15:00"
- 각 화면마다 기본 상태와 함께 빈 상태·로딩(스켈레톤)·오류 상태도 보여줘
```

## 1. 로그인 / 회원가입

```
[로그인·회원가입 화면]을 디자인해줘. 상단 내비와 비서 버튼은 없는 화면이야.

기능:
- 왼쪽: 서비스 소개 영역. 헤드라인 "말하면, 정리됩니다." / 부제 "흩어진 수업·과제·일정을 한 화면에. 떠오른 할 일은 그냥 말로 남기세요."
  특징 3개: ① 말로 남기면 AI가 정리("다음 주 화요일까지"도 정확한 날짜로) ② 시간표·구글 캘린더·메일 과제를 한 줄로 ③ 아침 브리핑을 읽어드려요
- 오른쪽: 로그인/회원가입 전환 탭 + 폼
  로그인: 이메일, 비밀번호, [로그인] 버튼
  회원가입: 이름, 이메일, 비밀번호(4자 이상), [가입하기] 버튼
- 폼 아래 작게 "체험 계정 student@vp.com / test1234"
상태: 버튼 누른 뒤 로딩, 오류 메시지("이메일 또는 비밀번호가 틀렸어요") + 폼이 살짝 흔들리는 효과
```

## 2. 대시보드 (홈)

```
[대시보드]를 디자인해줘. 로그인하면 가장 먼저 보는 화면이고, 오늘 하루를 한눈에 보는 게 목적이야.

구성 (위에서 아래로):
1) 오늘 영역: "김학생님, 좋은 오후예요" / 큰 날짜 "11월 23일 월요일" / "오늘 수업 2개 · 오늘 마감 1개"
   버튼 [브리핑 듣기](누르면 AI가 오늘 일정을 음성으로 읽어줌, 재생 중엔 [그만 듣기]로 바뀌고 읽는 문장이 아래 표시) [동기화](구글 캘린더·메일 새로고침)
   가운데 큰 마이크 버튼 + "눌러서 말하면 할 일로 정리돼요" → 음성 메모 화면으로 이동
2) 요약 카드 4개: 오늘 마감(1, 지난 마감 0개) / 이번 주 마감(6, 7일 이내) / 가장 가까운 마감(D-day, "운영체제 3장 복습") / 받은 편지함(2, 새 과제 후보)
3) 왼쪽 큰 카드 "타임라인": [오늘 | 이번 주] 전환. 수업·일정·마감을 시간순 한 줄씩
   - 수업: 10:00~12:00 심화응용프로젝트 · 공학관 301
   - 일정: 16:30~17:30 캡스톤 조 회의 · 도서관 스터디룸 · 출처 배지(구글/직접 추가)
   - 마감: 21:00 운영체제 3장 복습 · D-day
   - 지금 시각을 가로선으로 표시, 지난 항목은 흐리게
   - 구글 미연결이면 카드 위에 "구글 캘린더를 연결하면 일정도 여기에 모여요 [연결하기]", 연결 만료면 "다시 연결"
4) 오른쪽 카드 "오늘 이것부터"(AI 추천 Top3): 번호 + 할 일 제목 + 과목 칩 + 마감 + AI가 고른 이유 한 줄("오늘 밤 마감이라 가장 급해요")
5) 맨 아래 "이번 주 시간표": 월~금 주간 격자, 수업 블록(과목색) 클릭하면 과목 페이지로. 오른쪽 위 [시간표 편집]
빈 상태: 오늘 일정 없음, 남은 할 일 없음("오늘은 마음껏 쉬어도 돼요")
```

## 3. 음성 메모 — 짧은 메모

```
[음성 메모 화면의 '짧은 메모' 모드]를 디자인해줘. 떠오른 할 일을 말로 남기면 AI가 할 일 후보로 정리해 주는 핵심 기능이야.

구성:
- 상단 오른쪽: [짧은 메모 | 강의 녹음] 전환
- 녹음 카드: 큰 원형 마이크 버튼
  · 대기: "버튼을 누르고 말하세요"
  · 녹음 중: 버튼이 정지 아이콘으로 바뀌고 빨갛게, 음성 파형 애니메이션 + 타이머 00:12 + "듣는 중 · 다시 누르면 정지"
- 아래 큰 글씨 입력 영역: 말하는 동안 글자가 실시간으로 찍힘(확정된 글자는 진하게, 아직 인식 중인 글자는 흐리게). 직접 고쳐 쓸 수도 있음
  예: "데이터베이스 교수님이 다음 주 화요일까지 ERD 과제 내래 그리고 목요일에 퀴즈 있대"
- [AI로 정리하기] 버튼 (누르면 "AI가 정리하는 중…" 로딩)
- 결과 카드:
  · AI 요약 한 줄 "DB: ERD 과제(다음 주 화) / 퀴즈(목)"
  · "할 일 후보" 목록: 각 후보마다 체크박스 + 제목(수정 가능) + 마감 날짜·시간 + 우선순위(높음/보통/낮음) + 과목 선택
    예) ✔ ERD 과제 제출 · 2026-12-01 23:59 · 높음 · 데이터베이스 / ✔ 퀴즈 준비 · 2026-11-26 13:00 · 보통 · 데이터베이스
  · 체크 해제한 후보는 흐리게. 하단 [저장된 메모 보기] 링크와 [할 일로 저장] 버튼 → 저장 후 "할 일 2개를 저장했어요" 알림
상태: 브라우저가 음성 인식 미지원이면 마이크 대신 안내 배너("Chrome·Edge 권장, 아래에 직접 입력하세요"), AI 실패 시 요약 자리에 경고 + 원문은 저장됨 안내
```

## 4. 음성 메모 — 강의 녹음

```
[음성 메모 화면의 '강의 녹음' 모드]를 디자인해줘. 수업 시간 내내 녹음을 켜두면 10분마다 글로 받아써지고, 끝나면 AI가 요약해 주는 기능이야.

짧은 메모와 다른 점:
- 실시간 자막 대신 녹음 진행 상태가 핵심: 큰 타이머(예: 47:12), 파형, "녹음 중 · 10분마다 글자로 바뀌어요"
- 받아쓰기 진행 표시: "받아쓰는 중… (1개 남음)" — 10분 조각이 하나씩 글로 바뀌어 아래 입력 영역에 이어 붙음
- 받아쓴 전문은 길다(수천 자). 스크롤되는 긴 텍스트 영역으로
- 일부 조각 실패 시: "받아쓰지 못한 부분이 있어요" + [다시 시도] 버튼 (녹음은 사라지지 않음을 안심시키는 문구)
- 받아쓰기 중에는 [AI로 정리하기] 비활성
- 결과: 할 일 후보 대신 "강의 요약" 카드
  · 핵심 3~5줄(불릿)  예) • SJF는 실행 시간이 짧은 작업을 먼저 처리해 평균 대기 시간이 가장 짧다
  · [시험 포인트] 강조 블록 ★ SJF와 라운드 로빈의 평균 대기 시간 비교
  · [저장된 메모 보기]
```

## 5. 메모 목록 / 메모 상세

```
[메모 목록]과 [메모 상세] 두 화면을 디자인해줘.

메모 목록:
- 제목 "메모" + 총 개수, 오른쪽에 과목 필터(모든 과목/과목별)
- 목록 한 줄: 종류 아이콘(짧은 메모/강의 녹음) + AI 요약(없으면 원문 앞부분) + 과목 칩 + 날짜·시간 + 길이(00:08, 30:20) + 오른쪽 화살표
- 10개씩 페이지 번호
- 빈 상태: "아직 메모가 없어요" + [음성 메모 남기기]

메모 상세:
- 상단: 종류·과목 칩·날짜·녹음 길이, [삭제] (확인 대화상자 "이 메모를 삭제할까요?")
- AI 요약 카드 (강의면 핵심 불릿 + 시험 포인트)
- "이 메모로 만든 할 일" 목록 (마감·상태 표시)
- "원문" 카드: 받아쓴 전체 텍스트
```

## 6. 할 일 보드

```
[할 일 보드]를 디자인해줘. 할 일을 칸반 3열로 관리하는 화면이야.

구성:
- 상단: 제목 "할 일 · 7개 남음", 오른쪽 과목 필터
- 빠른 추가 바(한 줄): + 아이콘, 제목 입력("새로운 할 일 — 예) 운영체제 3장 복습"), 마감 날짜·시간, 우선순위, 과목, [추가]
- 3열: 할 일(5) / 진행 중(2) / 완료(4), 열 머리에 색 점과 개수
- 카드: 둥근 체크(누르면 완료로) + 제목 + 과목 칩 + 마감(D-day 색 규칙) + 우선순위 막대(높음 3칸·보통 2칸·낮음 1칸)
  + 출처 배지(음성 메모 / 음성 비서 / 메일 — 직접 추가는 배지 없음)
  + 하단 [시작하기 >] / [< 할 일로] [완료 >] 이동 버튼, 휴지통(확인 대화상자)
- 완료 카드: 체크됨, 제목 취소선, "완료 11/20" 표시, 흐리게
- 빈 열: "할 일이 없어요. 위에서 추가하거나 말로 남겨보세요"
```

## 7. 시간표 + 과목 추가/수정

```
[시간표] 화면과 [과목 추가·수정 시트]를 디자인해줘.

시간표:
- 제목 "시간표 · 3과목", 오른쪽 [+ 과목 추가]
- 주간 격자: 월~금(토·일 수업 있으면 추가), 9:00~18:00, 30분 단위
  수업 블록은 실제 시간만큼 세로로 길게, 과목색 옅은 배경 + 왼쪽 진한 선, 안에 과목명·시간·강의실
  오늘 요일 머리 강조, 오늘 열 옅게 칠하고 지금 시각 빨간 가로선
  블록 클릭 → 과목 모아보기
- 아래 "내 과목" 목록: 과목색 아이콘 + 과목명(클릭 시 과목 페이지) + "류교수 · 월 10:00~12:00" + [수정] [삭제]
- 빈 상태: "과목을 추가해 보세요 — 과목을 등록하면 AI가 메모에서 과목을 자동으로 찾아줘요"

과목 추가·수정 시트(가운데 팝업):
- 과목명, 교수(선택), 색상(프리셋 8개 + 직접 선택)
- 수업 시간 여러 줄: 요일 / 시작 / 끝 / 강의실 / 줄 삭제, [+ 시간 추가]
- [취소] [저장], 오류 "끝 시간은 시작 시간보다 늦어야 해요", "이미 있는 과목명이에요"
```

## 8. 과목 모아보기

```
[과목 모아보기] 화면을 디자인해줘. 과목 하나에 대한 모든 것을 모아 보는 페이지야. (예: 데이터베이스, 박교수, 색 #F5A86C)

구성:
- 상단: 과목색 점 + 과목명 + 교수, 오른쪽 [시간표에서 수정]
- 숫자 카드 4개: 남은 할 일(2, 전체 3개) / 완료율(33% + 과목색 진행 막대) / 음성 메모(1) / 수업(2, "화 13:30, 목 13:00")
- 왼쪽: 이 과목 할 일 목록 (상태 배지 할 일/진행 중/완료, 마감 D-day, 완료는 취소선)
- 오른쪽 위: 이 과목 음성 메모 목록 (요약 한 줄, 종류, 날짜)
- 오른쪽 아래: "메일에서 찾은 과제" (AI가 찾은 할 일 제목, 메일 제목, 받은 날짜, 상태 배지 새 후보/추가함/무시함)
- 각 영역 빈 상태
```

## 9. 주간 리포트

```
[주간 리포트] 화면을 디자인해줘. 이번 주(월~일)에 얼마나 해냈는지 돌아보는 화면이야.

구성:
- 제목 "주간 리포트 · 11/23 ~ 11/29"
- 숫자 카드 4개: 이번 주 완료(2, "지난주 1개 · ▲ 1" 초록/감소면 빨강) / 이번 주 마감 달성(25%, "8개 중 2개 완료") / 지난 마감(0, 남아 있으면 빨강) / 가장 열심히 한 날(월요일)
- 왼쪽 카드 "요일별 완료": 월~일 막대그래프, 막대 위에 개수
- 오른쪽 카드 "과목별 마감 달성": 과목명 + 2/4 + 과목색 진행 막대 (과목 없음은 회색)
- 아래 "이번 주 완료한 일" 목록: 체크 아이콘 + 제목 + 과목 · 11/23 11:20 완료
- 빈 상태: "아직 완료한 일이 없어요 — 하나씩 끝내면 여기에 쌓여요"
```

## 11. 연동 설정

```
[연동 설정] 화면을 디자인해줘. 외부 서비스 연결 상태를 관리하는 설정 화면이야. 그룹으로 묶인 설정 목록 형태로.

1) 구글 · 캘린더와 메일
- 구글 계정 행: 로고 + 상태 점(● 연결됨 student.kim@gmail.com / ● 연결 만료 / ● 연결 안 됨) + 오른쪽 [연결 해제] 또는 [구글 계정 연결]/[다시 연결]
- 연결 시 상세: 권한 배지(캘린더, 메일 읽기), "연결 11/21 · 마지막 동기화 26분 전", [지금 동기화]
- 그룹 아래 작은 안내: "테스트 버전 앱이라 7일마다 다시 연결이 필요할 수 있어요."
2) 노션 · 할 일 내보내기
- 상태 행 + Integration 토큰 입력(비밀번호처럼 가림) + 내보낼 데이터베이스 ID 입력 + 도움말 한 줄 + [저장]
- 연결 후: "토큰 ••••3f9a", [이번 주 할 일 노션으로 내보내기] → "할 일 5개를 내보냈어요"
- "토큰은 서버에만 저장되고 화면에 다시 보이지 않아요"
3) 음성
- 음성 인식: ● 사용 가능 · 한국어(ko-KR) / 미지원이면 "Chrome·Edge에서 사용하세요"
- 브리핑 읽어주기: ● 사용 가능 + [미리 듣기]
```

## 12. 음성 비서 패널

```
[음성 비서 패널]을 디자인해줘. 모든 화면 오른쪽 아래 "비서에게 말하기" 버튼을 누르면 열리는 떠 있는 대화 패널이야. 말로 일정 잡기·할 일 추가·마감 확인을 해.

구성:
- 패널 머리: "음성 비서" + 읽기 중지(스피커) + 닫기
- 처음: 안내 말풍선 "무엇을 도와드릴까요? 일정 추가, 마감 확인, 할 일 완료를 말로 해보세요."
  + 추천 문장 버튼 3개: "내일 오후 3시에 캡스톤 조 회의 잡아줘" / "이번 주 마감 알려줘" / "오늘 수업 뭐 있어?"
- 대화: 내 말(오른쪽 말풍선), 비서 답(왼쪽), 비서가 생각 중(점 3개 애니메이션)
- 듣는 중: 내 말풍선에 실시간 자막이 흐리게 찍히고, 하단 마이크 버튼이 빨간 파형으로
- 실행 결과 칩: "✓ 일정 추가 · 11/23 16:30", "✓ 완료 · 운영체제 3장 복습"
- 일정 충돌 제안 흐름(중요):
  나: "오늘 오후 2시에 캡스톤 조 회의 잡아줘"
  비서: "그 시간엔 운영체제 수업이 있어요. 오후 4시 30분은 어때요?" + [좋아] [다른 시간] 버튼 + 작은 안내 "‘좋아’라고 말해도 돼요"
  나: "좋아" → 비서: "좋아요. 오후 4시 30분에 캡스톤 조 회의를 추가했어요. 구글 캘린더에도 넣었어요." + 결과 칩
- 하단 입력 바: "말하거나 입력하세요" 입력창 + 마이크 버튼
- 비서 답은 음성으로도 읽어줌(읽는 중 표시)
```
