# Figma AI 프롬프트: 보이스 플래너 UI/UX

> 2026-11-23 작성. 기준: `@Dev.md`(화면 1~10, logic, 비기능 요구사항), `schema.sql` 샘플 데이터, 현재 `views/*.ejs` 구조.
> Figma Make / First Draft에 넣는 용도. 결과물은 **시각 시안 + 디자인 토큰**으로만 쓰고, 코드는 우리 EJS + 순수 CSS로 옮긴다 (Figma가 만든 React·Tailwind 코드는 쓰지 않음).

## 사용 순서

1. **0번 마스터 프롬프트**를 먼저 넣어서 디자인 시스템과 대시보드를 만든다. 한 번에 화면 12개를 요청하면 품질이 떨어지니까, 첫 결과에서 톤을 확정한다.
2. 마음에 들면 같은 파일에서 **1~12번 화면 프롬프트**를 하나씩 이어서 넣는다. 매번 "앞에서 만든 디자인 시스템을 그대로 써줘"가 붙어 있다.
3. 마지막에 **13번 토큰 정리 프롬프트**로 색·글꼴·간격을 표로 뽑는다. 이 표가 `public/css/style.css`의 `:root`로 들어간다.
4. 데스크톱 1280px과 모바일 390px 프레임을 둘 다 받는다.

## 0. 마스터 프롬프트 (디자인 시스템 + 대시보드)

```
대학생용 음성 플래너 웹앱 "보이스 플래너"의 UI를 디자인해줘. 모든 UI 문구는 한국어.

[서비스 한 줄]
말하면 AI가 할 일·마감·과목을 정리해주고, 시간표·구글 캘린더·학교 메일 과제를 한 화면 타임라인에 모아주는 대학생 허브.
핵심 행동은 "마이크를 누르고 말하기". 사용자는 수업 사이 쉬는 시간에 휴대폰으로 10초 안에 기록하고 확인한다.

[브랜드 성격]
- 차분하고 친절한 개인 비서. 정돈됨, 가벼움, 집중. 게임스럽거나 유치하지 않게
- 마이크가 주인공. 화면마다 "말하면 된다"는 게 바로 보여야 함
- 정보 밀도는 중간: 한눈에 오늘 할 일이 보이되 빽빽하지 않게

[디자인 시스템]
- 색: 메인 1색(차분한 블루~인디고 계열 추천), 중립 회색 단계, 상태색 4개(위험=마감 24시간 이내, 경고=3일 이내, 성공=완료, 정보)
- 과목 색: 사용자가 과목마다 임의의 색(hex)을 고른다(예: #6C8EF5, #F5A86C, #7CC9A0). 어떤 색이 와도 글자가 읽히도록
  과목 칩은 "연한 배경(과목 색 15% 틴트) + 과목 색 점 + 진한 글자" 방식으로 디자인해줘. 흰 글자를 과목 색 위에 올리지 말 것
- 글꼴: Noto Sans KR (Google Fonts). 제목/본문/캡션 3~4단계
- 모서리: 카드 16px, 버튼·입력 12px, 칩 999px
- 그림자: 아주 부드러운 1단계 + 떠 있는 요소(플로팅 마이크, 토스트)용 1단계
- 간격: 4px 단위 (4·8·12·16·24·32)
- 아이콘: 선형(outline) 아이콘 한 세트로 통일. 출처 아이콘 3개 필요: 시간표(수업), 구글 캘린더(일정), 할 일(마감)
- 라이트 모드 기본 + 다크 모드 변형

[공통 레이아웃]
- 데스크톱(1280): 상단 가로 내비게이션 [로고 "보이스 플래너"] [대시보드·음성 메모·메모 목록·할 일·시간표·받은 편지함·연동 설정] [관리자(관리자 계정만)] [사용자 이름 · 로그아웃]
  본문 최대 폭 1100px 가운데 정렬
- 모바일(390): 상단은 로고 + 사용자 메뉴만, 하단 탭바 5개(홈·할 일·시간표·편지함·설정). 음성 메모·메모 목록은 홈의 큰 마이크와 메뉴로 이동
- 모든 화면 오른쪽 아래에 "음성 비서" 플로팅 마이크 버튼(56px 원형). 모바일에서는 하단 탭바 위에 뜸
- 토스트 알림: 화면 아래 가운데, 2.5초 후 사라짐

[첫 화면: 대시보드 = 통합 타임라인] 데스크톱·모바일 둘 다
1. 헤더: "11월 23일 월요일" 큰 제목, 아래 "김학생님, 오늘도 화이팅!"
   오른쪽에 버튼 2개: [🔊 브리핑 듣기] (주 버튼), [동기화] (보조 버튼, 옆에 "마지막 동기화 10분 전" 작은 글자)
2. 요약 카드 4개(데스크톱 4열, 모바일 2×2):
   - 오늘 마감: 큰 숫자 "1", 아래 "지난 마감 0개"
   - 이번 주 마감: "3", 아래 "7일 이내"
   - 가장 가까운 D-day: "D-3" 빨강·주황 강조, 아래 할 일 제목 "DB 퀴즈 준비"
   - 받은 편지함: "새 후보 1개", 누르면 받은 편지함으로
3. 통합 타임라인 카드: 탭 [오늘] [이번 주]
   세로 타임라인, 시간순 한 줄씩. 각 줄 = 시간 | 출처 아이콘 | 제목 | 과목 칩 | 장소
   예시(오늘):
   - 10:00~12:00  [수업] 심화응용프로젝트 · 공학관 301
   - 16:30~17:30  [구글 일정] 캡스톤 조 회의 · 도서관 스터디룸
   - 23:59        [마감] ERD 과제 제출 · 데이터베이스 · D-8
   지금 시각을 가로선으로 표시. 지난 항목은 흐리게
   이번 주 탭은 날짜별로 묶음(11/24 화, 11/25 수…)
4. 가운데 큰 마이크 버튼(지름 120px, 모바일 96px) + 아래 "눌러서 말하면 할 일로 정리돼요"
5. "✨ 오늘 이것부터" 카드: AI가 고른 3개, 번호 목록. 각 줄 = 과목 칩 + 제목(굵게) + D-day + "— 마감이 내일이에요" 같은 이유 한 줄
   AI 연결 실패 시 제목 옆에 "(AI 연결 실패 · 마감순)" 작은 회색 글자

상태도 같이 그려줘:
- 불러오는 중: 카드 숫자 자리 스켈레톤
- 비어 있음: 타임라인 "오늘은 일정이 없어요", Top3 "남은 할 일이 없어요 🎉"
- 구글 미연결: 타임라인 위에 얇은 안내 배너 "구글 캘린더를 연결하면 일정도 여기에 모여요 [연결하기]"
- 구글 토큰 만료: 노란 배너 "구글 연결이 만료됐어요. 저장된 일정만 보여요 [다시 연결]"

[예시 데이터는 이걸 그대로 사용]
사용자 김학생 / 과목: 심화응용프로젝트(파랑 #6C8EF5, 월 10:00~12:00 공학관 301), 데이터베이스(주황 #F5A86C, 화 13:00~15:00·목 13:00~14:00 공학관 204), 운영체제(초록 #7CC9A0, 수 09:00~11:00 정보관 102)
할 일: ERD 과제 제출(데이터베이스, 12/1 23:59, 높음), DB 퀴즈 준비(데이터베이스, 11/26 13:00, 보통), 기말 발표 PDF 제출(심화응용프로젝트, 11/27 23:59, 높음)
일정: 캡스톤 조 회의(11/24 16:30~17:30, 도서관 스터디룸), 동아리 정기 모임(11/25 18:00~20:00, 구글)
메일 후보: "[데이터베이스] 기말 리포트 제출 안내" prof.park@example.ac.kr → 기말 리포트 제출, 12/5 23:59

[접근성]
글자 대비 4.5:1 이상, 터치 영역 44px 이상, 키보드 포커스 링 표시.
마감 임박은 색만으로 구분하지 말고 "D-1" 같은 글자를 항상 함께 표시.
```

## 1. 로그인 / 회원가입

```
앞에서 만든 디자인 시스템을 그대로 써서 "로그인 / 회원가입" 화면을 데스크톱·모바일로 만들어줘.
- 내비게이션 없음. 가운데 카드 하나(폭 380px)
- 카드 위: 로고 "🎙️ 보이스 플래너", 한 줄 소개 "말하면 할 일·마감·과목이 정리돼요"
- 데스크톱은 카드 왼쪽에 서비스 소개 영역 추가 가능: 마이크 → 할 일 카드로 바뀌는 간단한 일러스트 + 특징 3줄
  ("말로 남기면 AI가 마감까지 정리", "시간표·구글 캘린더·메일 과제를 한 화면에", "아침마다 오늘 브리핑을 읽어줘요")
- 탭 2개 [로그인] [회원가입] (세그먼트 컨트롤)
- 로그인: 이메일, 비밀번호, [로그인] 버튼 하나(카드 폭 전체)
- 회원가입: 이름(50자), 이메일, 비밀번호(8자 이상 안내), [회원가입] 버튼 하나
- 에러 상태: 버튼 위 빨간 글자 "이메일 또는 비밀번호가 틀렸어요" / "이미 가입된 이메일이에요"
- 버튼 누른 뒤 처리 중 상태(비활성 + 스피너)
```

## 2. 음성 메모 (STT → AI 분석 → 할 일 후보)

```
같은 디자인 시스템으로 "음성 메모" 화면을 데스크톱·모바일로. 이 서비스에서 두 번째로 중요한 화면이야.
헤더: "음성 메모" + 오른쪽 링크 "메모 목록 →"
탭 2개: [짧은 메모] [강의 녹음]
- 짧은 메모 안내: 예) "데이터베이스 교수님이 다음 주 화요일까지 ERD 과제 내래"
- 강의 녹음 안내: "강의를 켜두면 길게 받아 적고, AI가 핵심 3~5줄과 시험 포인트로 요약해요"

녹음 카드:
- 가운데 큰 원형 마이크 버튼 + 아래 상태 글자
- 인식된 내용 텍스트 영역(수정 가능, 최소 140px 높이). 확정된 글자는 진하게, 말하는 중인 임시 글자는 아래 회색으로 이어서 실시간 자막처럼
- [✨ AI 분석] 주 버튼

상태 5가지를 모두 프레임으로 그려줘:
1) 대기: 파란 마이크, "버튼을 누르고 말하세요"
2) 녹음 중: 빨간 마이크 + 바깥으로 퍼지는 펄스 링, "듣는 중… 다시 누르면 정지", 경과 시간 00:12, 실시간 자막이 찍히는 중
3) 분석 중: 버튼 "AI가 정리하는 중…" 비활성, 결과 영역 스켈레톤
4) 결과:
   - "AI 요약" 박스 (연한 배경, 여러 줄)
   - "할 일 후보 · 저장할 것만 체크하세요"
   - 후보 카드 2개. 각 카드: 왼쪽 체크박스(기본 체크) / 제목 입력칸(수정 가능) / 아래 한 줄에 마감(날짜+시간), 우선순위(높음·보통·낮음), 과목(드롭다운: 없음·심화응용프로젝트·데이터베이스·운영체제)
     예: "ERD 과제 제출" 12/1 23:59 높음 데이터베이스 / "DB 퀴즈 준비" 11/26 13:00 보통 데이터베이스
   - [할 일로 저장] 주 버튼, 아래 "저장된 메모 보기 →" 링크
   - 강의 녹음 결과는 후보 없이 요약만: "• 핵심" 3~5줄 + "[시험 포인트] ★ …" 1~3줄
5) 실패·미지원:
   - AI 실패: 요약 자리에 "AI 분석에 실패했어요. 메모 원문만 저장했어요." (경고 톤, 겁주지 않게)
   - 마이크 권한 거부: 빨간 안내 "마이크 권한을 허용해주세요"
   - 음성 인식 미지원 브라우저(Safari·Firefox): 마이크 숨기고 "이 브라우저는 음성 인식을 지원하지 않아요. 아래에 직접 입력하세요. (Chrome 권장)" + 텍스트 영역만
```

## 5. 할 일 보드 (칸반)

```
같은 디자인 시스템으로 "할 일 보드" 화면. 데스크톱 3열, 모바일 1열(또는 상단 세그먼트로 열 전환).
- 헤더: "할 일 보드" + 오른쪽 과목 필터
- 빠른 추가 카드(한 줄 폼): 할 일 제목(넓게) · 마감(날짜+시간) · 우선순위 · 과목 · [추가]
- 3열: [할 일 n] [진행 중 n] [완료 n]. 열 배경은 페이지보다 살짝 진한 회색
- 할 일 카드:
  - 왼쪽 4px 세로 띠 = 과목 색(과목 없으면 회색)
  - 제목(굵게)
  - 둘째 줄: 과목 칩 · D-day 라벨 "D-3 · 11/26 13:00" · "보통" · 음성 비서/AI로 만든 건 작은 마이크 아이콘
  - 버튼: 할 일 열 [시작 →], 진행 중 열 [← 이전] [완료 ✓], 완료 열 [← 이전] + 휴지통 아이콘

## 9. 음성 비서 (모든 화면 공통 플로팅)

```
같은 디자인 시스템으로 "음성 비서" 플로팅 컴포넌트를 상태별로 그려줘. 대시보드 화면 위에 올린 모습으로.

상태 6가지:
1) 듣는 중: 패널에 파형 또는 펄스 + 실시간 자막 "내일 오후 3시에 캡스톤 조 회의 잡아줘"

   아래 버튼 [좋아] [다른 시간] + 안내 "'좋아'라고 말해도 돼요"
5) 조회 답변: "이번 주 마감은 3개예요" + 작은 목록 3줄

- 비서 답변은 소리로도 읽어준다는 표시(스피커 아이콘, 읽는 중 애니메이션, 탭하면 정지)

## 13. 디자인 토큰 정리 (마지막)

```
이 디자인의 토큰을 CSS 변수 이름으로 표로 정리해줘. Tailwind 클래스가 아니라 실제 값(hex, px, rgba)으로.
라이트·다크 두 열로.
- 색: --bg, --card, --text, --muted, --line, --primary, --primary-dark, --primary-soft, --danger, --warn, --ok, --info, --column-bg
- 글꼴: --font, 제목/본문/캡션 크기·굵기·줄간격
- 모서리: --radius(카드), --radius-md(버튼·입력), --radius-pill
- 그림자: --shadow, --shadow-float
- 간격 단계, 반응형 기준 폭(모바일 760px 이하)
- 과목 칩 공식: 배경 = 과목색 몇 % 틴트, 글자색 규칙
```

|---|---|
