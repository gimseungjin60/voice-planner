### 4.5 CLAUDE.md 코드 규칙 준수

- SQL 전부 `?` 플레이스홀더. 동적인 부분은 코드에 고정된 컬럼명 조각(`where.push("t.status = ?")`)뿐
- 라우터 `try/catch → next(err)` 패턴, 응답 `{ok, data}` / `{ok:false, error}` 통일
- 라우터에서 SDK 직접 호출 없음 (전부 `services/ai.js`)
- 화면은 GET 렌더, 변경은 fetch → JSON
- 새 라이브러리 추가 없음 (package.json 그대로)
- EJS 출력은 `<%= %>` 이스케이프, JSON 임베드는 `<` → `<` 치환, 클라이언트 렌더는 `esc()` 사용

## 6. 미검증 항목 (검증 요청 포인트)

1. **DB 연동 전체**: 실제 MySQL에서 모든 쿼리가 돌아가는지 (특히 `tasks/summary`의 `SUM(조건)` 집계, `LIMIT ? OFFSET ?` 바인딩, admin 서브쿼리)
2. **Claude 응답 파싱**: `extractTasks`가 "다음 주 화요일"을 정확한 날짜로 바꾸는지, due_at 형식이 `YYYY-MM-DD HH:mm`으로 오는지
3. **Web Speech API**: Chrome에서 `continuous` + 자동 재시작이 정지 버튼 전까지 유지되는지, `/memo?start=1`로 들어왔을 때 사용자 제스처 없이 `start()`가 허용되는지
4. **TTS**: 한국어 음성이 없는 환경에서 `lang='ko-KR'`만으로 읽히는지
5. **시간대**: EC2(UTC)에서 `pool.kst()` 기준 오늘/요일이 맞는지
